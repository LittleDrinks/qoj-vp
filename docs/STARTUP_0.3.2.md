# 0.3.2 启动时直接恢复已有页面

0.3.1 只在原生助手的快照返回后恢复题表。新页面仍串行等待 hello、list_sessions、session_snapshot，因此助手启动慢时会出现 no contest 空白页。

现在同步从浏览器显示缓存恢复所选比赛、题目、提交记录及资源入口，再独立核对原生账本和 QOJ。去掉无用途的 hello 往返、正常连接提示和已有题表的更新文字；比赛进度条保留当前值，禁用从零滑动的过渡动画。没有任何缓存的首次打开仍须读取数据。

显示缓存按本地 session 分开，校验账号、比赛和计时范围；不保存源码、表单或下载内容。明确指定另一场比赛时不会显示上一场。删除比赛会淘汰对应显示缓存；损坏、禁用或空间不足的缓存不影响正常读取。原生快照核验前 Submit 保持禁用。实际连接或刷新失败仍有可重试的错误提示。
